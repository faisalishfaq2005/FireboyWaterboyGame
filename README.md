# 🔥💧 Fireboy and Watergirl - Terminal Edition

A terminal-based C++ game inspired by *Fireboy and Watergirl*, where two characters must work together to solve puzzles, avoid traps, and reach their respective portals.  
Built entirely with standard C++ and designed to run directly in the terminal — no graphics libraries needed.

---

## 🎮 Gameplay

- Control **Fireboy** and **Watergirl** through keyboard input.  
- Each character has unique movement and abilities.  
- Avoid hazards like water, fire, and spikes.  
- Work together to activate levers, open doors, and reach the exit safely!
